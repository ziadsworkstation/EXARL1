# Proyectos de Ziad

Un hilo por proyecto. Cada carpeta tiene una `FICHA.md` (objetivo, estado, próximos pasos) y un
`hilos/` con el resumen de cada conversación. Para seguir con un proyecto, abre una sesión nueva y di:
«Lee `proyectos/<carpeta>/FICHA.md` y seguimos».

| # | Proyecto | Estado | Ficha |
|---|---|---|---|
| 01 | Búsqueda de prácticas | En marcha (rutina diaria activa) | [FICHA](01-busqueda-practicas/FICHA.md) |
| 02 | Portfolio / web (ziadaddami.es) | Por definir | [FICHA](02-portfolio-web/FICHA.md) |

Al acabar cada conversación, añade un resumen en `hilos/AAAA-MM-DD_tema.md` y actualiza el estado de la ficha.
