# Làmina A3 — EXAR L1

`EXAR_L1_Addami_Ech_Chaouy_Ziad.pdf` — làmina final (A3 apaïsat, vectorial).

Regenerar (necessita `ezdxf`, `numpy`, `Pillow` i Playwright de Node):

```
python3 render.py   # render isomètric -> assets/render_iso.png (~1,5 min)
python3 build.py    # lamina.html -> PDF
```

Tipografies: Anton (títols) + Inter (text). Paleta: blau marí, blanc trencat i un accent
taronja (el to de les làmines/tèxtil).
